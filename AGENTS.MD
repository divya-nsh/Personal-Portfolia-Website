## About Project

This is Personal Portfolio Site of mine used to showcase my work, skills and about myself

## Tech Stack

- Reactjs + Nextjs + Typescript: At his Core
- MDX: For Projects Page
- Motionjs: For Animations

- App using Nextjs 16 With App Router

## Rules

- Use TypeScript only. `any` should only be used with good reason and comments.
- Write Short comment for complex piece of Code.
- Make the smallest change that solves the task. Don't refactor unrelated code without asking it you can suggest that changes.
- Write Clean And composable code
- Make Sure SEO is Optimised
- The site rarely changes. Keep the shared `SITE_LAST_UPDATED` date for the sitemap; no need for per-page `lastModified` tracking or recommend it as an SEO improvement unless explicitly requested.
