## Overview

A Windows desktop app that connects price checker kiosks to a store's existing pricing data. When a customer scans a barcode, the kiosk calls the middleware's Express API, which looks up the product in the store's datasource and returns the price along with promotional media and other information.

```
Android kiosk ── barcode ──► Middleware (Windows / cloud) ──► CSV · MSSQL · PostgreSQL · REST API
              ◄─ product + price ─
```

## Features

- **Pluggable datasources:** CSV, MSSQL, PostgreSQL and REST APIs, with field mapping and a built-in lookup test.
- **Multi-store support:** per-location datasources, with a `{{location_code}}` placeholder for queries and API calls.
- **Device management:** kiosks self-register, and an admin can change their template or location.
- **Screen templates:** promo banners and media are managed centrally and synced to devices automatically.
- **Easy deployment:** runs on a store PC or a cloud server, starts with Windows and lives in the system tray.
- **Licensing:** key activation, with one active machine per license.
